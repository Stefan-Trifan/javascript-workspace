# JS-WORKBENCH

Este repositorio recopila mis apuntes, prácticas y ejemplos desarrollados durante el curso de Udemy:  
**"JavaScript: El Curso Completo, Práctico y desde Cero"** (35 horas).

Incluye ejercicios y conceptos clave como:

- Fundamentos del lenguaje
- BOM (Browser Object Model)
- DOM (Document Object Model)
- Fetch API y otras APIs del navegador
- Uso de módulos en JavaScript moderno

El objetivo de este repositorio es servir como espacio de pruebas y repaso práctico mientras avanzo en el curso.
